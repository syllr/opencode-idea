## 一、已固化的固定流程

## 二、这些配置怎么跑 / 停 / 重启

<!-- 生成提示:begin -->

逐个已固化的配置判定它属于哪一类,**只保留真正出现的那几行**。判据是**跑完会不会自己退**。
<!-- 生成提示:end -->

- **一次性 Job(跑完即退)** → `<前缀>_execute_run_configuration`。
- **长驻进程(起来不退)** → `<前缀>_rerun_run_configuration`(在跑就重启、没在跑就启动),**不要**用 `execute_run_configuration` —— 它会起出重复实例。
- **停** → `<前缀>_stop_run_configuration`(停掉该配置的**全部**实例,幂等)。**不要** `kill` / `pkill`:外部杀掉的进程 IDE 不知道,Run 窗口仍显示运行中,下次启动就会撞端口。
- 停 / 重启前后先 `<前缀>_list_running_configurations` 看**真实状态**(几个实例 / 各自 pid),别凭 Run 窗口的显示判断。
- 这一组工具不存在时(没装配套插件)**交给用户**:请他在 IDEA 里手动跑 / 停。
