`{...}` / `<...>` 是占位，落盘时替换掉。

- **干什么、什么时候跑只写在 description**：正文不重复，那是模型加载前唯一看得到的线索。
- **步骤不固定**：数量不限，每步可以是一个脚本、一条命令、一次工具调用，也可以是一组连续动作。
- **有差异才画表**：标题下用无序列表写要点（做什么、注意什么）；这一步在不同系统 / 环境做法不同，才在列表下加表格（差异可能是换脚本、换命令、换配置）；没有差异就把做法直接列成一条。
